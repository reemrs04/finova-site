# Finova — financial decision platform concept demo

A bilingual Arabic/English static concept website. It demonstrates a unified customer and Relationship Manager journey, with product comparison, personal financing simulation, deposits, and investments.

All bank figures are fictional examples for demonstration only. They are not real offers, rates, or financial advice.

## Pages

- `index.html` — platform overview and financing simulator
- `product-comparison.html` — product comparison tables and category interactions

## Deploy

The site is hosted on Netlify. Connect this repository to the existing Netlify project and deploy the repository root.
